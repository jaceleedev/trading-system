# 첫 검증 규칙 momentum-v1

이 설정은 최적화 결과나 실제 계좌의 확정 거래 조건이 아니다. 비교 실험을 시작하기 위한
사전 명시 가정이며 `configs/research.json`과 추천 결과에 함께 보존한다.

- 현물 매수 전용. 최대 6종목. 종목 20%, 업종 40%, 국가 70%를 상한으로 둔다.
  국가별 고정 배분은 없다. 기본 목표는 전체 평가액의 1/6이며 상한·가용현금·주문 단위에
  따라 줄인다. 적합한 후보가 적으면 현금이 남는다.
- KR/US별 데이터·유동성 조건을 통과한 종목을 조정가격의 12개월 전~1개월 전 수익률로
  순위화한다. 기준 날짜는 판단 시각의 시장 현지 날짜이며 각 기준일 이전 최신 자료를 쓴다.
  기준일에서 7일 넘게 떨어진 자료는 거부하고 구간 내 관측 180개 이상을 요구한다.
- 신규 진입은 해당 시장 상위 30%, 보유 유지 후보는 상위 50%다. 정확한 비율은 rank/N이다.
  동률은 영구 ID로 결정한다. INDEX 업종은 비교지수용 표식으로 후보에서 제외한다.
- 최근 20개 관측의 평균 거래대금이 KR 10억원, US 1천만달러 이상인 종목만 후보로 둔다.
  이것은 슬리피지나 체결 가능성의 보증이 아니다. 최신 무거래 관측도 거부한다.
- 기존 보유 후보를 우선 검토하고, 그 다음 시장 내 상대순위·모멘텀·ID 순으로 후보를 채운다.
  월 1회 정기 평가를 위한 규칙이며 CLI 호출 자체가 주문이나 매매일 강제를 뜻하지 않는다.
- 기존 보유도 상한에 맞춰 축소할 수 있다. 점수·데이터 조건에서 탈락한 보유분은 매도 검토
  대상이다. 단, 보유 종목의 가격·환율 누락/노후화나 상장폐지는 정상 매도로 가정하지 않고
  전체 추천을 중단한다. 자동 손절선이나 전체 계좌 낙폭 중단 규칙은 아직 추가하지 않았다.
- 매수 총비용 가정은 KR 20bp/US 40bp, 매도는 KR 40bp/US 40bp다. 수수료·세금·환전·
  체결 불리함을 포함한 연구용 합산값이며 실제 증권사 조건과 다를 수 있다.
  비용 상한을 미리 현금으로 남기고 정수 수량을 절사해 가용현금 초과 매수를 막는다.
- 첫 주문 단위는 국내·미국 모두 1주다. 토스 소수점/금액 주문은 별도 거래 프로필을 확인한
  뒤 추가해야 한다. 원화 현금과 주식만 지원하며 실제 USD 현금·환전 원장은 아직 미지원이다.
- 추천은 계좌 snapshot을 바꾸지 않는다. 매도 예상 대금으로 이후 매수를 계산한 결과는
  가상 재배치이며, 실제 결제·주문 가능금액은 증권사 확인이 필요하다. 모든 가격은 참고값이다.

추천은 dataset 해시, 전략 소스 해시, 규칙, 당시 계좌, 판단 시각, 후보와 탈락 이유를 보존한다.
입력과 코드가 같으면 같은 추천 ID를 만든다. 저장한 추천을 같은 ID로 수정할 수 없다.
보유·진입 조건의 수익성은 확인되지 않았다. 합성 데모로 확인하는 것은 계산과 화면 동작뿐이다.
