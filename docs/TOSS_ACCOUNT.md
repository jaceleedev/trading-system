# 토스 계좌 조회와 AI의 계좌 문맥

이 기능은 공식 OpenAPI v1.2.15의 계좌·보유 주식·매수 가능 금액·수수료·진행 중 주문을
읽고, 조회 당시의 원응답과 요약을 로컬에 보존한다. 계좌를 변경하거나 주문하지 않는다.

## 처음 연결

[인증 설정](TOSS_AUTH.md)을 마친 뒤 계좌 목록을 확인한다.

```sh
uv run trading toss-account list
```

출력에는 계좌번호를 포함하지 않고 계좌 선택용 `account_seq`와 계좌 종류만 표시한다.
반환된 계좌를 확인해 명시적으로 선택한다. 아래 `1`은 실제 계좌를 조회한 결과가 아닌
명령 형식 예시다.

```sh
uv run trading toss-account sync --account 1
uv run trading toss-account show --id <저장된-스냅샷-ID>
```

`show`는 네트워크나 키체인에 접근하지 않고 저장된 내용을 확인한다. `sync`는 새 시점의
자료를 읽으며 과거 스냅샷을 덮어쓰지 않는다. 각 API 조회가 성공하면 원응답을 보존하고,
필수 조회와 검증이 모두 성공해야 전체 스냅샷을 저장한다. 중간 실패의 관측값을 완성된
계좌 상태로 게시하지 않는다. 원응답과 스냅샷은 Git에서 제외한 `var/accounts/`에 저장한다.
디렉터리는 사용자 소유 0700, 파일은 0600이며 공개 권한의 기존 위치는 거부한다.

## 금액의 의미

- **매수 가능 금액**은 증권사가 보고한 해당 통화의 주문 가능 금액이다. 실제 현금 잔고나
  출금 가능 금액으로 바꾸지 않으며 KRW와 USD의 값을 합산하지 않는다.
- 실제 현금 잔고는 이 API 조합으로 확인되지 않아 `null`로 남긴다. 누락값을 0으로 채우지 않는다.
- 보유 주식의 원화·달러 평가액은 각 통화로 거래되는 종목의 별도 합계다. 같은 총액을 두
  통화로 표현한 값이라고 가정하지 않는다. 별도 검증한 환율 없이 총자산을 만들어내지 않는다.
- 수량·금액·수수료율은 소수 문자열로 보존한다. 소수점 보유 수량을 정수로 절사하지 않는다.
- 수수료율은 세금·환전비용 등 모든 비용을 포함한다는 의미가 아니다. 적용 시작·종료일도
  함께 확인하며 실제 투자 비용 모델로 자동 채택하지 않는다.

## 조회 범위

보유 주식 조회는 국내·미국 주식에 한정되며 채권·옵션 등 계좌의 모든 자산을 포괄하지 않는다.
진행 중 주문은 Open API가 지원하는 주문 유형에 한정된다. 일부 앱 시간외 주문과 조건주문은
이 목록에 포함되지 않으므로 **모든 미체결 약정이나 자금 예약을 확보했다고 표시하지 않는다**.

각 요청은 순차로 발생한다. 조회 시작·종료 시각과 개별 관측 시각을 남기며 원자적인 한 시점의
계좌로 취급하지 않는다. 시점이 오래되면 재조회해야 한다. 실제로 조회한 시각을 과거 자료의
공개 시각으로 바꾸거나 백테스트용 데이터라고 선언하지 않는다.

필수 필드·소수 표기·통화 대응·페이지 완결성을 검사한다. 공식 계약이 확장을 허용하는
알 수 없는 코드는 보존하고 검토 대상으로 표시한다. 이 앱의 현물 계좌 가정과 맞지 않는
음수 보유량은 정상화하지 않고 거부한다. 오류 응답 본문·HTTP 헤더·토큰은 저장하거나 출력하지 않는다.

현재 모멘텀 계산의 `Account`는 확정된 원화 현금과 정수 주식을 요구하므로 새 스냅샷을
그 형식으로 자동 변환하지 않는다. AI 조사 도구는 새 스냅샷의 원래 의미와 미확인 항목을
그대로 읽어야 한다. 해시 일치는 로컬 기록의 무결성 검사이며 계좌의 완전성이나 수익성 증명이 아니다.

계약 출처: [토스 공식 OpenAPI](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json).
현재 클라이언트가 사용하는 응답 계약은 패키지 안에 고정해 런타임에 최신 명세를 내려받지 않는다.

2026-09-10 사용자가 설정한 키로 실제 계좌 목록과 6개 관측의 전체 스냅샷 수집을 검증했다.
종합매매 계좌 1개에서 보유 종목 3개와 조회 범위 내 진행 중 주문 0개를 확인했다.
테스트에는 사용자 계좌 원문 대신 공식 문서 예시와 합성 변형만 사용한다.
