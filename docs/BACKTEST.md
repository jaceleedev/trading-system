# 과거 시점 시뮬레이션

```bash
uv run trading db-upgrade
uv run trading backtest --dataset synthetic-demo-v1 \
  --simulation configs/backtest.demo.json --save > var/backtest.json
```

이 명령은 합성 자료로 회계와 연구 흐름을 시연한다. 실제 시장 수익률이나 전략의 우위를
측정한 결과가 아니다. `--save`는 데이터·코드·설정 해시를 포함한 결과를 PostgreSQL에 저장한다.
동일 입력은 같은 ID이며 내용이 다른 결과로 덮어쓰지 않는다.

## 시간과 체결

- 시작일 종료 시점과 매월 말 UTC 일 종료 시점에 추천을 계산한다. 장 종료와 공개 시각이
  판단 시점 이전인 가격만 신호에 사용한다.
- 결정 후 첫 번째 공급자 거래일의 **종가**로 가상 체결한다. 결정 당시의 종가로 즉시
  체결한 것으로 계산하지 않는다. 7일 내 다음 봉이 없으면 미체결 사유를 남긴다.
- 매도·매수는 실제 이벤트 시각 순서로 처리한다. 같은 시각에는 매도가 먼저다.
  실제 체결일 가격과 비용으로 매수 가능 수량을 줄이며 현금 부족을 차입으로 채우지 않는다.
- 종가 경매 체결 가능성, 호가, 가격 제한, 상하한가, 거래 정지와 결제일을 완전히 재현하지
  않는다. 원화 현금에서 즉시 환전·결제하는 모형이다. 종가 가정의 민감도 검증이 필요하다.
- 자료 부족·노후화·상장폐지 회수액 미지원 조건을 임의의 가격으로 채우지 않고 중단한다.

## 납입과 수익률

월 납입은 설정일 00:00 UTC(한국 09:00)에 이루어진다. 초기 자본과 누적 외부 납입은
`external_net_krw`, 평가액과 그 차이는 `net_pnl_krw`다. 납입 전 평가액을 기준으로
가상 펀드 좌수를 발행하여 납입 자체가 시간가중수익률(TWR)을 바꾸지 않게 한다.
최대 낙폭은 이 좌당 평가액으로 계산하며, 1년 미만 결과에는 연환산 수익률을 표시하지 않는다.

한국·미국 비교 기준은 각각 명시한 INDEX 종목에 초기 자본과 월 납입을 정수 단위로
투자하는 별도 가상 계좌다. 전략은 월말에, 비교 계좌는 납입 후 다음 거래일에 자금을
투자한다. 이들은 투자 시점·국가·변동성 노출이 다르며 엄밀한 동일 위험 비교는 아니다.

## 주식 분할과 배당

`manifest.json`에 선택적으로 `corporate_actions` 배열을 선언한다. 행마다 모든 키가 필요하다.

```json
{
  "event_id": "example-split",
  "instrument_id": "PROVIDER-PERMANENT-ID",
  "kind": "split",
  "effective_at": "2025-03-09T23:00:00+00:00",
  "known_at": "2025-03-01T00:00:00+00:00",
  "payment_at": null,
  "ratio": "2",
  "cash_per_share": "0",
  "withholding_bps": "0"
}
```

분할 비율은 신주/구주다. 현금 배당은 `kind: cash_dividend`, `ratio: 1`, 양수인
주당 총 배당금, 배당락 이후 지급 시각, 0 이상 10000 미만의 원천징수 bps를 입력한다.
숫자는 정확한 십진 문자열을 권장한다. 배당락 시각의 보유 수량으로 세후 미수 배당을
확정하고 지급 시점의 환율로 현금을 받는다. 중간에 매도해도 이미 생긴 권리를 유지한다.
원가격으로 평가하며 조정 종가 수익률을 계좌에 한 번 더 더하지 않는다.

분할·배당이 발생하면 해당 종목의 미체결 주문을 취소하고 사유를 남긴다. 첫 행사 후 봉이
나오기 전 원가격은 분할 비율·총 배당금으로 기계적으로 조정하여 평가한다. 이는 실제
호가가 아니다. 새 단위의 가격이 없으면 관련 재판단을 보류하며 이후 일 종료 시점에
재시도한다. 다른 자료 오류는 숨기지 않는다. 소수 잔여 주식의 현금 정산은 지원하지
않아 추천 시점에 중단한다. 기준계좌의 추가 납입 판단은 기존 미체결 매수를 취소·대체하여
같은 현금을 중복 예약하지 않는다.

원가격 대비 조정가격 비율이 달라졌는데 기업행사가 선언되지 않으면 백테스트를 거부한다.
이 검사가 공급자의 배당 금액·조정 방식·과거 종목군·세법을 인증하지는 않는다. 알려진
기업행사 이외의 변화, 합병·분할상장·상장폐지 등은 공급자 어댑터와 별도 정책이 필요하다.

## 검증 상태

평탄한 가격에서 납입은 손익·TWR을 바꾸지 않고, 분할·세전 배당은 가치가 중복되지 않는지
검사한다. 체결이 판단 이후인지, 미래 종료일을 연장해도 앞선 곡선이 같은지, 비용과
현금이 원장에서 일치하는지 검사한다. 이는 구현의 정확도 검사다. 실제 자료에 대한
독립 기간 검증, 매매 비용 실측, 전향적 모의운용은 별도 단계다.
